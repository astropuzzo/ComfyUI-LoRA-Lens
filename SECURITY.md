# Security policy

Please report security-sensitive findings privately through GitHub's security advisory feature rather than a public issue.

Imported API workflows can execute any installed ComfyUI node. Only import workflows from sources you trust and inspect unfamiliar custom nodes before installation. LoRA Lens validates workflow structure but cannot make an untrusted third-party node safe.

The project never needs private model weights, datasets, API keys, or personal reference images in a bug report.
